# Checklist de mise en ligne

- [ ] Coller `apps-script/Code.gs` dans le projet Apps Script du Google Sheet.
- [ ] Créer la propriété de script `SHEET_API_KEY`.
- [ ] Déployer Apps Script comme application Web accessible à tout le monde.
- [ ] Copier l'URL `/exec` dans `GOOGLE_APPS_SCRIPT_URL` sur Vercel.
- [ ] Ajouter `ADMIN_PASSWORD` avec la valeur demandée.
- [ ] Ajouter un `AUTH_SECRET` aléatoire différent du mot de passe.
- [ ] Ajouter la même `SHEET_API_KEY` dans Vercel.
- [ ] Redéployer le site.
- [ ] Tester la connexion.
- [ ] Tester un changement En attente → Payé et vérifier le Google Sheet.
- [ ] Vérifier que la colonne `status` a été créée.
